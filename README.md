# Pixel Live Studio Android

Android MVP for converting selected MP4 videos into Android Motion Photo-style JPEG files.

## Build

GitHub Actions builds a debug APK on pushes to `main`/`master` or via manual workflow dispatch. The workflow uploads an Actions artifact and publishes the installable APK directly to GitHub Releases as `PixelLiveStudio.apk`.

## Important

This is an MVP. Validate generated motion photos with the target Android gallery and Douyin version. Compatibility may vary by device and app version.
